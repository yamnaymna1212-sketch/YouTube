# Kai | Money Stories

Animated Shorts (9:16, 30-40 s) about the money moments Americans live through. Glowing stickmen in a navy "blueprint neon" city. Everything, including every frame and every sound effect, is generated by code in this repo.

| Read | What it is |
|------|------------|
| `CLAUDE.md` | Channel rules (format, niche, hook, owner preferences) |
| `WORKFLOW.md` | **How to make an episode**: tools, scripts, step by step |
| `STORY_BIBLE.md` | Characters, story so far, Part 3 draft, idea backlog |
| `POSTED.md` | Published videos, links, titles, captions |
| `NEW_SESSION_PROMPT.md` | Message to paste to start a new session in the same style |
| `style/glow-style-bible.md` | Visual style (characters, world, motion, UI) |

## Folders
- `episodes/ep01-the-5am-call/`, `episodes/ep01-part2-the-door/`: finished videos, voice lines (`audio/`), scripts, storyboards
- `brand/source/`: the code (`ep02.js` template, `glow.js` characters, `world.js` world and props, `mix.py` sound, `tts.py` voices)
- `brand/v2-glow/`: character, world, props and motion-test images and videos
- `brand/tiktok/`: profile name, bio, avatars, hashtags
- `style/references/`: the reference images the style came from
- `DOPAMINE | An Animated Short Film.mp4`, `ssstik.io_*.MP4`: the original reference videos
- `brand/0*.png`, `style/neon-noir-style-bible.md`, `scripts/`: archived first style and the first (Dana) draft, not used
