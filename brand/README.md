# 2 AM Stories: Brand Kit

Concept art for the channel, in the Neon Noir Diorama style (`../style/neon-noir-style-bible.md`).

| File | What it is |
|------|------------|
| `01-mascot-echo.png` | Echo, the channel mascot: the glowing "inner voice" that appears in every story |
| `02-character-dana.png` | Dana character sheet: anchor details, 3 expressions, palette |
| `03-world-key-art.png` | The world: rainy Ohio street at 2:14 AM, apartment, gas station |
| `04-logo-and-icons.png` | Channel avatar and 8 neon topic icons |
| `05-youtube-banner.png` | YouTube banner, 2560x1440, logo inside the safe area |
| `06-thumbnail-template.png` | Thumbnail template, 1280x720 |

These are vector concept images (`.svg` files are editable). Use them as reference images in Midjourney/Flux to get the final 3D miniature look.

Re-render after editing: `node brand/source/build.js brand` (needs Playwright).
